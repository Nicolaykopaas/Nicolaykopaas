## Prosjekter

| Prosjekt | Hva det er | Teknologi | Lenker |
|---|---|---|---|
| **Randonee-ruteplanlegger** | Kartapp for toppturer på ski i Romsdal. Rutene er beregnet ut fra terrengmodell og bratthet i stedet for tegnet for hånd, og appen viser skredvarsel og vær på toppene live. Kan vises i 3D med høydeprofil for hver tur. | ArcGIS Online, ArcGIS Maps SDK for JS, JavaScript | [Live demo](https://nicolaykopaas.github.io/randonee-ruteplanlegger/app/) · [Repo](https://github.com/Nicolaykopaas/randonee-ruteplanlegger) |
| **VisitTrondheim** | Lager en gåtur i Trondheim sentrum ut fra hvor lang tid du har og hva du vil gjøre. Alle stedene har ekte bilder fra Wikimedia, og ruta er den korteste av 60 rekkefølger. | React, TypeScript, MapLibre, OpenStreetMap, OSRM | [Live demo](https://nicolaykopaas.github.io/visittrondheim/) · [Repo](https://github.com/Nicolaykopaas/visittrondheim) |
| **AnbudsRadar** | Henter offentlige anbud fra Doffin og finner småbedriftene som faktisk kan ta jobben. Gir hver match en score og lager ferdige e-postutkast. | Python, pandas, Streamlit | [Live demo](https://anbudsradar.streamlit.app/) · [Repo](https://github.com/Nicolaykopaas/anbudsradar) |
| **Byggeradar** | Samler nye byggetillatelser fra kommunene og sorterer dem etter fag, så håndverkere ser hvor det skal bygges. | Python, Streamlit | [Live demo](https://byggeradar.streamlit.app/) · [Repo](https://github.com/Nicolaykopaas/byggeradar) |
| **Boligregnskap** | Holder styr på inntekter, utgifter og forfall for utleieboliger, og lager årsrapport med skatteanslag. Anslår markedsleie med data fra Kartverket og SSB. | Java, Spring Boot, H2 | [Live demo](https://boligregnskap.onrender.com) · [Repo](https://github.com/Nicolaykopaas/boligregnskap) |
| **adkiller** | Chrome-utvidelse som blokkerer annonser i flere lag. | JavaScript, Manifest V3 | [Repo](https://github.com/Nicolaykopaas/adkiller) |
